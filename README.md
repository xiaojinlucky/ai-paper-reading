# 用 AI 读机制论文：从研究问题到证据判断

把论文读成可以讨论和借鉴的研究思路，需要看清问题、实验与结论怎样相连。生命科学机制论文往往篇幅宏大、图表繁复，正文呈现的是经过作者精心重构的逻辑叙事，而非真实的实验探索曲折。如果仅凭大模型进行全文速读，极易被流畅的叙述带偏，将“组织相关性”误读为“分子因果”，甚至漏掉关键的功能对照。

本项目基于真实的科研精读与带教经验，系统总结了一套从“小标题骨架提取”、“因果单跳拆解”、“图表四问核查”到“三段式结论重构”的文献精读方法学。结合一篇真实的卵巢癌肿瘤微环境顶刊案例（Licaj et al., *Nature Communications* 2024），完整呈现了提示词模板、原始模型回答、幻觉对质纠偏与课题迁移方案，旨在为生命科学研究者提供一套严密、可复用、不易翻车的文献研读心法。

## 一、精读方法论：生命科学机制论文的因果判读法

### 1.1 三个底层认知

1. **读懂不是读完。**
   读懂一篇机制文献的标准只有三条：
   - 能在脑海中画出这篇论文的主线**节点链**；
   - 能给链上的每一跳（hop）清晰说出其**证据级别**（实线因果 vs 虚线相关）；
   - 能明确指出这条链**缺了哪一环**、缺的那一环**值不值得自己动手去做**。
   做不到这三条，机械地通读全文十遍也是浮于表面。

2. **论文的顺序是叙事（辩护词），不是史实。**
   Introduction 从宏大背景层层收窄，凝练出一个看似顺理成章的科学问题；Results 环环相扣，展现出完美的论证闭环。但必须清醒认识到：**写作与做实验是两码事**。论文是作者在拿到所有阳性结果后精心构筑的“辩护词”，充满了后验重组的逻辑包装。如果顺着作者的线性叙事从头读到尾，很容易被牵着鼻子走，看不见作者有意回避或缺失的对照。

3. **证据的单位不是“整句断言”，而是“单跳”（Hop）。**
   当论文声称“分子 A 通过介导 B 抑制细胞功能 C”时，这句话实际上包含了两个独立的跳跃：**A→B** 与 **B→C**。
   顶刊中非常普遍的现象是：A 对 B 的调控做了详尽的敲除、过表达和回补实验（实线，因果确证）；但在 B 对 C 的环节，往往只提供了临床样本的相关性散点图，或是外源添加重组蛋白的表型观察（虚线，未确证内源介导）。把整句话当作一个结论来接收，等于把最弱的一跳误认作最强的一跳。

### 1.2 骨架提取与“挂三件”

精读机制文献最忌讳一上来就逐字翻译长文、死磕陌生的实验细节。正确的第一步是先抓骨架：

- **第一步：抄加粗小标题。** 打开 Results，只摘录每个大 Figure 对应的加粗小标题。**一个大 Figure 对应一个小标题，对应一句核心主张**。纵向排列这几句话，先建立整篇论文的粗骨架；
- **第二步：给每个节点“挂三件”。** 回到正文，为每个小标题节点提炼出实验设计的核心三要素：
  1. **怎么分组**（处理组与关键对照组是什么）；
  2. **做了什么操作**（干预手段、剂量、时间窗、检测技术）；
  3. **数据怎样分析**（读出指标是什么、统计单位是切片/供体还是细胞）。
- **第三步：区分表型与机制，用“词接龙”连线。**
  - **表型（Phenotype）**：整体动物模型层面的生长、转移、生存期，或细胞层面的增殖、凋亡、迁移；
  - **机制（Mechanism）**：分子/通路层面的结合、磷酸化、转录激活或入核定位。
  每段的第一两句通常是动机句（“为了阐明……因此我们检验……”）；上一段结尾落脚的概念，通常是下一段开头的研究对象（词接龙）。用实线（有干预因果）和虚线（仅共变相关）将节点连接起来，即可清晰还原出整篇论文的逻辑图谱。

### 1.3 审图三件套与图件效力分层

**图注不是正文的缩写，图注是看懂图的说明书。**
读图必须严格落实审图三件套：横纵坐标量纲、对照组设置、误差棒与分母（n 的真实代表单位）。同时，在阅读与借鉴中必须将关键图件划定为三种证据效力：

- `[装饰]` **装饰性引用**：仅作背景展示或技术验证（如模型构建成功示意图）。哪怕去掉该图，核心科学假设的因果论证依然成立；
- `[证据]` **证据性引用**：承载特定的因果推论，但其结论边界严格受限于该 Panel 的特定实验条件（如特定效靶比、干预时间窗或单一细胞系）；
- `[接管]` **结构性接管**：读者能够凭这张图的对照组骨架，在自己实验室的体系里重建一组可判读的对照闭环，并能预判其失效位点。

### 1.4 三段式结论重构

任何一次严密的文献阅读，收尾时都必须产出“三段式”的结论重构，绝不机械照抄摘要：

1. **当前实验确实支持什么**：写清特定体系、时间窗、浓度和对照下成立的客观事实；
2. **当前证据尚不能推出什么**：明确列出未经验证的推论越级、未闭合的机制中介与外推限制；
3. **最小判别实验 / 课题切入点**：针对论文留下的虚线断裂或矛盾表型，设计出能打通因果的最精简实验，转化为自己手头的研究课题。

## 二、怎样使用这套方法与提示词

### 用自己的论文

1. 准备目标论文的文本段落、关键分图及其完整图注；
2. 复制[阅读提示词](prompts/reading_workflow.md)，将其中的案例问题替换为你自己关切的科学假设（务必包含对象、处理、比较与读出四要素）；
3. 遵循“先拿大标题骨架，再核查关键图件三件套，最后做三段式修正”的节奏，避免被大模型生成的流畅摘要掩盖了事实错误。

### 在科研计算平台中使用

1. 在科研计算平台（如[玻尔科学空间](https://www.bohrium.com)）新建长文任务，上传[论文摘录](cases/input_paper.md)和[阅读提示词](prompts/reading_workflow.md)作为输入附件；
2. 实测表明，处理超长论文（包含完整 Results 与 Methods）时，直接粘贴易发生截断，使用附件上传更为稳妥；
3. 平台助手在遇到长篇文献时，往往采用滑动窗口分块补读（如 1–40、40–69 等多窗口回读）。此时需重点核对模型是否真正读全了 Methods 中的统计学说明，以及是否把附图（Supplementary Figures）漏判为“未进行实验”；
4. 真实使用任务记录、连续原文截取与长文分块优化心得，详见材料包附录中的 `cases/bohrium_practice.md`。

### 跟着本案例练习

1. 阅读[论文摘录](cases/input_paper.md)，重点对照 `[P9]`、`[P12]` 和 Fig. 4/6 的图注；
2. 分别查看[普通提问回答（Baseline）](cases/baseline_output.md)与[结构化提问回答（Workflow）](cases/ai_output.md)，注意观察普通提问如何将“间质 YAP1 下降”泛化为“全身 YAP1 下降”，以及如何遗漏了补充材料中 CYR61 的关键功能实验；
3. 深入精读[原文核查记录](cases/verification.md)与[组会避坑指南](cases/evaluation.md)，掌握如何抓住原图细节纠正 AI 幻觉与推论越级。

## 三、真实案例：YAP1、CYR61 与 CD8 T 细胞功能

本案例选用 Licaj 等发表在 *Nature Communications* (2024;15:1312) 上的高分研究，剖析高浸润卵巢癌微环境中基质细胞与免疫抑制的复杂相互作用。

### 3.1 核心因果链条的拆解

通过加粗小标题与动机句，我们可以将论文的庞杂数据凝炼为一条核心主线：

```
化疗处理 ──(相关)──> ANTXR1+ ECM-myCAF 减少 ──(表型)
   │
   ├──(测量)──> 基质 YAP1 总量及核定位下降 (Fig. 4)
   │
   └──(干预)──> siYAP1 / siCYR61 ──(体外功能)──> 恢复 CD8+ T 细胞杀伤 (Fig. 6, S7)
```

### 3.2 容易踩坑的四处因果断裂

在阅读和模型生成过程中，极易出现以下推论越级，必须依托原文核查予以澄清：

1. **细胞归属的混淆**：
   - 论文在 Fig. 4F 中报告化疗后间质（Stroma）总 YAP1 H-score 下降，但在 Fig. 4J 右侧同时报告了癌细胞（Cancer cells）核内 YAP1 阳性比例亦下降。不能将“间质改变”片面总结为“上皮细胞完全无变化”。
2. **总量改变与核易位的混淆**：
   - YAP1 作为 Hippo 通路的核心转录共激活因子，其功能主要取决于**核定位比例**，而非单纯的总蛋白丰度。模型初读时极易将免疫荧光测量的“核内阳性百分比”等同于“总蛋白表达量”。
3. **YAP1 与 CYR61 的调控单跳未打通**：
   - 论文在 P12 提出“YAP1 通过转录靶基因 CYR61 发挥功能”，并分别证明了 siYAP1 能改善 T 细胞杀伤（Fig. 6），siCYR61 也能改善 T 细胞杀伤（Suppl. Fig. S7）。
   - **关键缺环**：该论文在当前体系中**并未展示 siYAP1 后 CYR61 表达量下降的直接实验**，更未进行“siYAP1 基础上回补 CYR61”的 Rescue 拯救实验！这是两条并行的单跳，尚不能推出内源性轴线完全闭合。
4. **统计单位的偷换**：
   - Fig. 4N/O 的组织微阵列涉及 10 张切片，来自 8 位供者；Fig. 6 共培养实验标注 $n=5$ 独立实验。模型初读时常将 $n=5$ 误认为 5 位患者，实际上仅为同一批或有限供者细胞的多次技术/生物学重复。

## 四、在组会与课题中借鉴这篇论文

### 4.1 组会汇报的防翻车法则

在组会文献汇报中，评委或导师最常发难的往往不是实验技术本身，而是“结论是否越过了证据边界”。
利用 [cases/evaluation.md](cases/evaluation.md) 整理的 **8 类高频因果断裂清单**，汇报者可以建立坚固的答辩防线：
- 当被问及“这个靶点能否作为体内治疗靶点”时，从容回答：“本文仅在体外共培养体系中验证了 siRNA 的抑制效应，尚未在小鼠同种移植瘤模型中进行体内干预，因此目前定位为体外功能贡献，尚不能外推为临床成药靶点”；
- 当被问及“是否证明了 YAP1-CYR61 轴线”时，主动指出：“原文分别完成了两个靶点的敲低实验，但缺乏上位阻断（Epistasis）与功能拯救（Rescue）证据，机制中介假说仍有待进一步验证”。

### 4.2 从文献取课题：从“虚线缺环”中挖掘创新

高水平论文留下的**未闭合虚线环**与**未验证边界**，恰恰是后继课题最优质的创新切入点：

1. **补全缺环（做深机制）**：
   针对本文未打通的 YAP1 $\to$ CYR61 轴线，在患者来源 CAF 中敲低 YAP1 后检测 CYR61 的转录与分泌蛋白水平，并在 siYAP1 体系中外源加入重组 CYR61 观察杀伤表型是否被反转（拯救实验），即可将假说推进为扎实的因果确证；
2. **反向求证（寻找相反条件）**：
   化疗后基质 YAP1 下降，但仍有部分患者发生化疗耐药。这部分耐药患者体内是否存在 YAP1 持续激活或旁路分泌（如其他 TEAD 靶基因 CTGF）？通过对照耐药与敏感队列，即可衍生出全新的耐药机制课题；
3. **对照骨架的直接迁移**：
   借鉴本文 Fig. 6 的共培养体系（CAF + 肿瘤特异性 CD8+ T 细胞 + 杀伤读出），直接套用于自己感兴趣的基质细胞亚群（如肌成纤维细胞 vs 炎性成纤维细胞），设计规范的阴性对照、溶剂对照与多靶比梯度，快速搭建起自己实验室的表型筛选平台。
