# 机制审定、组会避坑与课题迁移指南

本指南为生命科学研究者提供从“阅读他人论文”向“接管实验设计与落地避坑”的转化工具，包含组会高频因果断裂避坑清单、课题迁移可行性评分卡（TFS）以及最小先导实验设计协议。

---

## 一、组会避坑清单：八类高频因果断裂与识破法则

在文献阅读或组会汇报中，模型与初读者常因“文字流畅”而忽略深层因果断裂。以下梳理八类最高频的推论陷阱：

| 因果断裂类型 | 典型假象与翻车台词（AI/初读常见原句） | 审稿人硬核查与识破词 | 必须追加的补救实验 |
|---|---|---|---|
| **1. 药理当遗传** | “Verteporfin 处理后杀伤指标恢复，证明免疫抑制依赖 YAP1 通路。” | “Verteporfin 具有光敏活性和自噬脱靶效应，药理抑制剂 ≠ 靶点特异性。” | 至少 2 条独立 siRNA 敲低交叉印证 + siRNA-resistant YAP1 WT 遗传回补。 |
| **2. 单侧当闭环** | “敲低 YAP1 后 CD8+ 杀伤活性回升，证实 YAP1 是诱导免疫抑制的核心驱动因子。” | “单侧失功能只能谈‘必要性贡献’，不能谈‘驱动因’，缺获得功能（GoF）验证。” | 构建 YAP1-5SA（组成型激活）或外源回补，检验表型是否呈对称镜像加剧。 |
| **3. 相关当介导** | “YAP1 能转录激活 CYR61，且敲低 CYR61 同样恢复杀伤，说明 YAP1 通过 CYR61 抑制免疫。” | “平行干预两节点 ≠ 上位调控轴闭环，缺少遗传上位阻断（Epistasis）。” | YAP1-5SA 过表达同时加入 CYR61 中和抗体；若表型未被中和，则介导假说被否证。 |
| **4. 标志物当受体** | “单细胞分析显示 ANTXR1 与纤维化评分极显著相关，说明 ANTXR1 介导了下游信号转导。” | “相关标志物 ≠ 功能受体；bulk TCGA 去卷积或共表达只能证明‘共存’，不能证明在因果链上。” | 对 ANTXR1 进行基因敲除或抗体阻断，检测 YAP1 核定位是否改变。 |
| **5. 细胞自主与旁分泌混淆** | “原代 CAF 与 CD8+ T 细胞共培养降低了 T 细胞杀伤，证明 CAF 改造了 T 细胞内在分化。” | “未排除物理接触、营养竞争或培养基酸化，细胞自主表型与旁分泌效应混淆。” | 设立无细胞接触的 Transwell 小室对照，或采集 CAF 条件培养基（CM）单独处理 T 细胞。 |
| **6. 统计单位虚假膨胀** | “本研究共纳入 24,205 个细胞/spots 进行分析，具有极高的统计学效力（p < 0.001）。” | “Pseudoreplication 伪重复！测量单元（spots/孔）被偷换为独立生物学单元（患者/小鼠）。” | 以独立患者或动物为统计分母，采用混合效应模型（Mixed Models）进行层次聚类分析。 |
| **7. 替代终点冒充机制** | “qPCR 检测到转录因子表达上调 2 倍，证实微环境重塑已被显著激活。” | “mRNA 表达变化不等于蛋白水平变化，更不等于分泌活性或生物学功能发生质变。” | 配套 ELISA 定量分泌蛋白 + 功能性生物读出（杀伤率、侵袭转移）。 |
| **8. 体外向体内盲目外推** | “体外共培养 1:1 比例证实免疫抑制，因此靶向该轴在体内具有确切抗肿瘤疗效。” | “体外人工比例（1:1）严重偏离体内微环境真实比例，忽略了 3D 基质物理屏障。” | 建立人源化小鼠模型或同种同源移植瘤（如 4T1），检验靶向抗体体内存活期。 |

## 二、课题迁移评估：TFS 可行性评分卡（10 分制 + 一票否决）

当你计划把本篇论文的机制（如 YAP1/CYR61 调控轴）迁移到自己的课题体系（如肺癌/胰腺癌类器官或小鼠模型）时，禁止凭主观印象开工，必须严格填报 **TFS（Translation Feasibility Score）评分卡**。

### 2.1 六维打分标准（满分 10.0 分）

| 维度 | 分值权重 | 核心提问 | 打分锚点（客观客观对照） |
|---|---|---|---|
| **M1 机制同源性** | 0–2.0 分 | 该通路/分子在你的目标病理体系中是否内源表达且处于激活态？ | • 0 分：靶点不表达或极低；<br>• 1.0 分：表达但通路呈未激活基线；<br>• 2.0 分：目标亚群高表达且已知有核定位。 |
| **M2 读出可达性** | 0–2.0 分 | 论文的核心功能读出在你的实验室平台是否具备直接测定条件？ | • 0 分：无杀伤/脱颗粒测定平台且无可信替代；<br>• 1.0 分：需换用简易替代读出（如仅测 LDH）；<br>• 2.0 分：流式脱颗粒、ELISA 与杀伤读出成熟可测。 |
| **M3 干预可控性** | 0–2.0 分 | 是否具备经过特异性验证的扰动手段（siRNA/慢病毒/抗体）？ | • 0 分：无有效扰动工具；<br>• 1.0 分：仅有单药抑制剂，缺乏遗传学序列；<br>• 2.0 分：2 条独立靶向序列 + 阴性对照 + 重组蛋白回补齐备。 |
| **M4 主体可获得性** | 0–2.0 分 | 关键实验主体（原代 CAF、自体/异体 T 细胞、类器官）能否稳定获得？ | • 0 分：临床标本或伦理断链；<br>• 1.0 分：依赖外部低频协作且活性不稳定；<br>• 2.0 分：伦理齐备、原代分离建系稳定可控。 |
| **M5 判读可靠性** | 0–1.0 分 | 能否严格定义独立生物学重复、执行双盲计数与跨板校准？ | • 0 分：无法定义独立批次（仅孔内重复）；<br>• 0.5 分：可做生物学重复但无法实现双盲；<br>• 1.0 分：独立生物学批次 ≥3，配备同批溶剂对照与双盲。 |
| **M6 资源与周期** | 0–1.0 分 | 先导实验所需的试剂耗材与周期是否在可控范围内？ | • 0 分：试剂定制周期 > 3 个月或超预算；<br>• 1.0 分：试剂均有现成货源，2 周内可完成先导摸底。 |

**决策阈值分级**：
- **≥ 8.0 分**：迁移方案成熟，直接启动五组对照先导实验；
- **6.5 – 7.9 分**：属于条件可行，必须先开展零成本的基线表达确认，补齐特异性对照；
- **5.0 – 6.4 分**：机制风险较高，仅限开展分子层面的描述性验证，严禁直接推进动物实验；
- **< 5.0 分**：**强制终止迁移**，重新评估靶点。

### 2.2 六项一票否决红线（命中任一直接熔断，不得计分）
- **[V1] 核心读出无法客观定量**：无流式或定量读出，仅依赖肉眼观察形态；
- **[V2] 干预手段特异性不明**：仅有单一市售小分子抑制剂，无任何敲低或遗传验证；
- **[V3] 伦理或取材链条缺失**：关键人源样本未获得正规伦理审批或取材极不稳定；
- **[V4] 统计学重复层级不清**：把同一细胞皿内的 3 个孔算作 n=3，并以此作为假设前提；
- **[V5] 论文关键结论存在数据硬冲突**：原图图注与画面不符（如 Fig. 6F 迁移组）且未见作者勘误；
- **[V6] 假说依赖单一片面证据**：整条因果链仅由单一间接指标支撑，无任何功能性 Rescue 证据。

## 三、保姆级最小先导实验协议（五组对照闭环设计）

当课题通过 TFS 评估准备落地时，禁止大水漫灌铺板，必须执行包含 **G0–G4 五组闭环对照** 的最小先导实验（Pilot Assay）。

### 3.1 对照组别设计与预期判读

```
               [G0] 溶剂对照 / 同型对照 (Vehicle / IgG)
                          │  (确立体系本底)
                          ▼
               [G1] 基线活化组 (CAF + T cell, 效靶比 1:5)
                          │  (观察到杀伤读出受抑，确立表型模型)
               ┌──────────┴──────────┐
               ▼                     ▼
      [G2] 失功能对照 (LoF)    [G3] 获得功能对照 (GoF)
      (siYAP1 或 siCYR61)      (外源重组 CYR61 回补)
      杀伤受抑被部分解除       表型进一步受抑
               └──────────┬──────────┘
                          ▼
               [G4] 上位阻断验证 (Rescue / Epistasis)
               (YAP1-5SA 过表达 + CYR61 中和抗体)
               观察表型是否被特异性撤销，闭环因果调控轴
```

### 3.2 跨板校准与成功判据
1. **同批次平行性**：G0 至 G4 必须由同一批次分离的原代 CAF 与同批次 T 细胞在同一 96 孔板（或平行板）内完成，严禁拼接不同月份的数据；
2. **跨板阴性校准**：每块读数板必须设置 3 孔单细胞悬液作为荧光/OD 本底校准，变异系数（CV）必须 < 8%；
3. **判决标准**：
   - **成功判据**：G1 与 G0 相比杀伤显著受抑（p < 0.05）；G2 与 G1 相比杀伤显著回升（必要性成立）；G4 杀伤恢复至 G2 水平（中介轴特异性成立）；
   - **重试/终止判据**：若 G0 与 G1 无统计学差异，提示原代细胞批次失去表型活性，必须更换原代来源，不得继续向下测试。
